# COMP1238 - Introduction to Data Management

## Week 1 - History
- Cuneiform was written on clay tablets
- Babylonians used a base-60 number system
- The printing press made books cheaper

## Week 2 - Bits and Bytes
- A bit can be either 0 or 1
- One byte contains 8 bits
- RAM loses data when the power is off

## Week 3 - Text Structure
- Markdown uses symbols to format text
- HTML uses tags to structure web pages
- UTF-8 can represent many different characters

## Week 4 - Text Editors
- Touch typing helps us type faster
- VS Code is a popular text editor
- Regex helps find patterns in text

## Week 5 - Command Line
- CLI lets us control computers with commands
- 'ls' lists files and 'cd' changes directories
- SSH lets us connect to remote computers
